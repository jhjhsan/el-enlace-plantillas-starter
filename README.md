# El Enlace Plantillas — Starter (Landing WhatsApp)

Plantilla **1 página** hecha con **Vite + React + TailwindCSS** para vender/clonar rápido.
✅ **Sin backend. Sin base de datos. Sin pagos.**  
✅ Todo se edita desde **1 solo archivo**: `src/config.js`

---

## Qué es
Una landing enfocada en conversión por WhatsApp:
- Secciones listas: Hero / Servicios / Precios / FAQ / Contacto / Footer
- CTA principal + botón flotante a WhatsApp
- Responsive (mobile-first)
- Configuración centralizada (sin tocar componentes)

---

## Qué incluye
- ✅ SPA 1 página (Vite + React)
- ✅ TailwindCSS
- ✅ Config editable: `src/config.js`
- ✅ Botón flotante WhatsApp (`FloatingWhatsApp`)
- ✅ Build/Preview listo para producción

---

## Qué NO incluye (importante / para evitar soporte)
- ❌ Instalación en tu hosting / dominio
- ❌ Soporte técnico 1:1 / mantenimiento
- ❌ Personalización a medida
- ❌ Integraciones (pagos, CRM, formularios con backend, etc.)
- ❌ Cambios de diseño, secciones extra, copywriting, SEO avanzado

> Política: esta plantilla se vende “as-is”. Incluye instrucciones, no incluye servicios.

---

## Requisitos
- Node **20+** recomendado
- npm (incluido con Node)
